[![CI](https://github.com/Magicapple-Coder/WechatAnalysisAssistant/actions/workflows/ci.yml/badge.svg)](https://github.com/Magicapple-Coder/WechatAnalysisAssistant/actions/workflows/ci.yml)

一个用于分析、浏览和导出本地微信聊天记录与朋友圈快照的 Windows 工具，包含
Electron 桌面端源码和从源码启动的本机网页版；项目不提供托管网页服务。

> [!IMPORTANT]
> 项目仍处于 Beta 阶段，目前只支持 Windows 10/11 与电脑版微信 4.x。请先备份重要数据，并只分析你有权访问的账号。不要向 Issue 上传聊天数据库、密钥、API Key 或未经脱敏的日志。
>
> **发布状态（2026-08-27）：`0.1.0-beta.3` 目前仅提供源码，尚未发布对应 Git tag
> 或 Windows 安装包。** 当前 PyAV Windows 原生依赖存在尚未解决的 GPL 与构建来源
> 证明问题，公开二进制构建会被合规门禁主动阻断。请勿从第三方下载声称属于本项目的
> 安装包；详情见 [第三方许可清单](THIRD_PARTY_NOTICES.md)。

## ✨ 功能特点

- 🔑 **自动提取密钥** — 从微信进程内存中自动获取数据库解密密钥
- 💬 **聊天浏览** — 像微信一样浏览所有聊天记录，支持搜索和过滤
- ✅ **选择导出** — 可勾选特定消息，或按时间范围筛选导出
- 📤 **多格式导出** — 支持 HTML（网页）、JSON、CSV、TXT 四种导出格式
- 🎨 **美观界面** — 仿微信风格的 Web 界面，绿色聊天气泡
- 🔍 **全文搜索** — 支持按关键词搜索聊天内容
- 🖼️ **聊天图片** — 可选择是否在聊天气泡中显示本地缓存图片
- 🖥️ **批量触发高清** — 用户打开范围内首张图片后，通过受窗口与输入状态校验约束的 Windows 前台自动翻页触发微信下载高清缓存
- 🤖 **图片识别** — 手动选择消息或时间范围后调用用户配置的视觉模型生成简短描述
- 🎙️ **语音转写** — 手动选择消息或时间范围后调用用户配置的语音模型生成文字
- ✨ **AI 分析报告** — 对所选聊天记录或朋友圈进行分块总结，支持预设、强度、详细程度和自定义要求
- 🌄 **朋友圈导出** — 按联系人（包括自己）和日期范围导出本机缓存的朋友圈、点赞与评论
- 🔒 **本地优先** — 浏览、解密和导出默认都在本地；图片识别、语音转写、AI 分析或朋友圈媒体下载只在用户明确触发后联网

## 🖥 系统要求

- **操作系统**：Windows 10 / 11（x64）
- **微信**：仅支持电脑版微信 4.x，并需要在本地登录过微信（有聊天数据）
- **桌面安装包**：当前暂停公开发布；恢复后才会提供无需另装 Python 或 Node.js 的产物
- **源码运行**：Python 3.10+（CI 验证 3.10 与 3.12），Node.js 20.19+（推荐 22 LTS）

## 🚀 快速启动

### 方法一：Windows 桌面版

`0.1.0-beta.3` 暂无可公开下载的 Windows 安装包。维护者正在替换无法完成公开再分发
证明的 PyAV/FFmpeg 原生运行时；在精确 DLL 哈希、许可证文本和对应源码均通过门禁前，
构建与发布工作流会失败。不要运行来自网盘、Actions 临时产物或第三方页面的同名
安装程序。

### 方法二：源码一键启动网页版（推荐开发者使用）

双击 `restart.bat`。脚本会创建隔离的 Python 环境，按
`backend/requirements.txt` 安装运行依赖、按前端 `package-lock.json` 安装 Node
依赖，随后构建前端并打开浏览器。若 8520 端口由其他程序占用，脚本会停止并提示，
不会结束无关进程。项目没有 Python 依赖 lockfile；发布构建工具的精确版本另见
`packaging/requirements-build.txt`。

网页版的界面、数据库读取、解密和导出均运行在本机：浏览器只访问 `127.0.0.1`
上的本地后端，并不会把聊天数据库上传到托管网站。图片识别、语音转写、AI 分析
和缺失媒体下载仍可能在用户明确触发后访问其配置的第三方服务。

### 方法三：手动启动

```powershell
# 1. 安装后端依赖
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r backend\requirements.txt

# 2. 构建前端
npm --prefix frontend ci
npm --prefix frontend run build

# 3. 启动服务
.venv\Scripts\python.exe -m backend.main --port 8520

# 4. 打开浏览器访问
# http://127.0.0.1:8520
```

### 方法四：前后端开发模式

```powershell
# 终端 1：启动后端
.venv\Scripts\python.exe -m backend.main --no-browser

# 终端 2：启动前端开发服务器
npm --prefix frontend ci
npm --prefix frontend run dev
# 访问 http://localhost:3000
```

## 📖 使用说明

### 1. 获取解密密钥

微信使用 SQLCipher 加密数据库，需要密钥才能读取。有两种方式获取:

**自动提取** (推荐):
- 确保微信正在运行并已登录
- 点击「自动提取」按钮从微信进程内存中提取密钥
- 提取成功后密钥会被保存，下次无需重复操作

**手动输入**:
- 如果你已知密钥，可以直接在界面中输入
- 密钥格式: 64 位十六进制字符串

### 2. 浏览聊天记录

- 左侧列表显示所有聊天联系人
- 点击联系人查看聊天记录（默认显示最新消息）
- 支持按消息类型过滤（文本/图片/语音等）
- 支持关键词搜索
- 可通过聊天顶部开关显示/隐藏图片；关闭时不会解密或加载图片
- 可在设置中选择智能、高清优先或流畅模式；智能模式列表加载缩略图，点击后显示本地最高可用画质，缺少高清文件时自动降级为缩略图
- 微信 `wxgf/HEVC` 高清缓存会在本机转换为浏览器可显示的 JPEG；特殊表情中的 WXGF/WXAM/裸 HEVC 会尽量保留为动态 WebP，WXAM 的颜色流与透明遮罩流会自动合成，HEIC/HEIF/AVIF/BMP/TIFF 会统一转成浏览器兼容格式。转换全部在本机完成，不要求额外安装系统 FFmpeg
- 微信 4.x V2 图片需要独立的图片 AES key；可在「设置 → 图片解密」点击「自动获取」
- 已保存的图片 AES key 可在输入框中点击「显示」按当前账号读取；普通设置接口仍不会返回密钥明文
- 自动获取时只需选择当前登录的微信账号，无需预先打开聊天图片。工具会优先从本地账号元数据派生并用已有 V2 图片交叉验证，必要时再扫描本机微信内存；成功后按当前账号保存，不在页面显示密钥明文
- 若自动扫描受权限限制，可尝试以管理员身份启动本工具；XOR key 通常可保持 `auto`
- 本项目仅支持电脑版微信 4.x 的聊天浏览、图片关联、语音转写、朋友圈预览与导出

### 模型接口与设置页

设置页按用途分为「聊天图片 / 图片识别 / 语音转写 / 内容分析 / 分析预设 / 导出」六个分区。图片识别、语音转写和内容分析采用一致的配置顺序：先选择服务商预设，再确认 Base URL 和模型，填写访问凭证与任务默认值；请求头、字段映射、JSON 模板等较少使用的参数位于高级连接设置中。

常用服务商预设如下：

| 功能 | 内置预设 |
|------|----------|
| **图片识别** | OpenAI、Anthropic Claude、Google Gemini、Azure OpenAI / Microsoft Foundry、阿里云百炼 / 通义千问、Moonshot / Kimi、智谱 GLM、火山方舟 / 豆包、腾讯云 TokenHub、硅基流动 SiliconFlow、OpenRouter、Ollama、LM Studio |
| **语音转写** | OpenAI、Azure OpenAI / Microsoft Foundry、阿里云百炼 Qwen-ASR、Groq Whisper、Mistral Voxtral |
| **内容分析** | OpenAI、Anthropic Claude、Google Gemini、Azure OpenAI / Microsoft Foundry、DeepSeek、阿里云百炼 / 通义千问、Moonshot / Kimi、智谱 GLM、火山方舟 / 豆包、百度智能云千帆、腾讯云 TokenHub、硅基流动 SiliconFlow、OpenRouter、Groq、Ollama、LM Studio |

这些条目主要是常用地址、模型和鉴权方式的配置预设，并不代表每个服务商都使用一套新的底层协议；其中多数服务复用 OpenAI 兼容协议。原生 Anthropic、Gemini、DashScope ASR，以及完全自定义 JSON / multipart 接口由各自适配器处理。也可以选择「其他 OpenAI 兼容接口」后手动填写服务，或使用完全自定义接口。连接本机回环地址的 Ollama、LM Studio 预设允许不填写 API Key；若本地服务启用了鉴权仍可填写，其他服务按后端返回的鉴权要求检查配置。

### 3. 识别聊天图片

1. 在「设置 → 图片识别」中选择服务商预设、「其他 OpenAI 兼容接口」或完全自定义接口，再填写相应 URL、模型名称和所需的 API Key；高级连接设置还可配置请求体、鉴权头与响应文本路径。
2. 打开一个聊天，点击「图片识别」。
3. 选择已勾选消息、指定日期范围或整个聊天，然后确认。
4. 识别结果会缓存在本机，并显示在图片下方。浏览图片本身不会调用模型。

### 4. 批量获取高清图片

1. 打开一个聊天，点击「批量获取高清」，选择当前加载范围、日期范围或整个聊天（单次最多 500 张）。
2. 按页面提示，在电脑版微信中手动打开指定时间的第一张未高清图片。
3. 保持微信图片查看器在前台，按 `Ctrl+Alt+F9` 开始；`Ctrl+Alt+F10` 暂停，`Ctrl+Alt+F11` 停止。
4. 运行期间不要操作鼠标键盘、移动或遮挡微信窗口。任何焦点、窗口或用户输入变化都会触发安全暂停。

该功能不调用微信私有 CDN，也不注入微信进程。它只发送单次左右方向键，并同时验证 `message_resource.db` 状态、高清文件大小稳定性以及实际图片解密结果。已验证高清会自动跳过；微信明确标记为不可用的历史图片会记为“过期”并立即继续，不计入失败，也不会中断剩余范围。设置中可调整新任务默认的“单张最大等待时间”和“验证成功后最短停留时间”，创建任务时也可临时覆盖；暂停期间不会消耗这两个计时预算。自动翻页失败时可在任务提示中改用手动翻页：每次在微信查看器中只切换一项媒体，再按 `Ctrl+Alt+F9` 确认，程序会继续验证和处理后续图片。

### 5. 导出聊天记录（图片与描述）

- HTML 默认把聊天图片以内嵌 `data:` 数据的方式写入单个文件，可离线打开或转发
- 可选择“高清优先”或“缩略图”；高清不存在或转换失败时自动降级
- 选择“用图片描述替换图片消息”后不再重复嵌入图片

> 隐私提示：识别时会把所选范围内、尚未命中本地描述缓存的图片发送给你配置的 API 服务。工具不会发送联系人名称、聊天上下文或本地文件路径。
> 远程模型 Base URL 必须使用 HTTPS；只有 `localhost`、`127.0.0.0/8` 或 `::1` 可使用 HTTP。

### 6. 导出格式与范围

支持四种导出格式:

| 格式 | 说明 |
|------|------|
| **HTML** | 美观的网页格式，包含聊天气泡样式，可直接在浏览器打开 |
| **JSON** | 结构化数据，方便程序处理和二次开发 |
| **CSV** | 表格格式，可用 Excel / WPS 打开 |
| **TXT** | 纯文本格式，通用性最好 |

支持三种导出方式:
- **全部导出**: 导出整个聊天的所有消息
- **选择导出**: 勾选特定消息后导出
- **时间范围导出**: 指定起止日期，只导出该时段的消息
- 可勾选「用图片描述替换图片消息」；已有描述会导出为 `[图片内容] ...`，未识别图片仍保留 `[图片]`

### 7. 生成聊天记录或朋友圈 AI 分析报告

1. 在「设置 → 内容分析」选择服务商预设、「其他 OpenAI 兼容接口」或完全自定义接口，填写 Base URL、模型和所需的独立 API Key。
2. 可在设置中新增、编辑或删除分析预设。每个预设都包含名称、分析强度（快速/均衡/深入）、报告详细程度（简洁/标准/详细）和默认分析要求。
3. 聊天记录可在聊天顶部点击「AI 分析」，选择已勾选消息、日期范围或整个聊天；勾选消息后也可直接点击底部「AI 分析选中」。
4. 朋友圈可点击顶部「朋友圈导出/分析」，先按联系人、日期或逐条动态确定范围，再点击「AI 分析总结」。
5. 每次分析前都必须单独确认将所选文字发送到配置的模型接口。完成后可在窗口内预览 Markdown 报告并下载；报告也会保存到设置的导出目录。

为避免静默遗漏，聊天和朋友圈单次最多各分析 5,000 条记录；超过上限会要求缩小范围。较长内容会按所选分析强度进行有界分块和分层汇总。单个任务最长运行 12 分钟、同时最多运行 2 个任务，运行中可点击「停止分析」。聊天图片只使用本机已有的图片描述，语音只使用已有转写；朋友圈只发送正文、位置、媒体数量以及点赞评论文字，分析过程不会额外上传图片、语音或视频文件。

> 隐私提示：AI 分析会把明确选择范围内的文字内容发送给用户配置的第三方模型服务商。请先确认范围内不含不希望上传的隐私或敏感信息，并了解对应服务商的数据处理政策。

### 8. 导出联系人朋友圈

1. 在聊天列表页面点击顶部「朋友圈导出/分析」。
2. 搜索联系人并点击「查看」，右侧会分页展示该联系人保存在本机的朋友圈文字、媒体数量、位置和互动；本人会显示「我」标签。
3. 选择导出范围：全部本地动态、同一日期范围，或在预览中逐条精确勾选动态。
4. 进入导出设置，选择文件名以及 HTML、JSON、CSV、TXT 格式后开始导出。
5. 单联系人直接生成所选格式文件；多联系人自动生成 ZIP，并附带索引页。

导出内容包括正文、发布时间、类型、位置、媒体元数据以及本机仍保存的有效点赞和评论；已撤回互动不会导出。预览本身不会联网加载图片，也不会把微信媒体 token 发送给前端。朋友圈数据来自电脑版微信 4.x 的本地 `sns.db` 快照，并不代表联系人完整历史：从未在电脑上加载、已经被微信清理或当前不可见的动态无法恢复。默认不会访问网络；只有勾选「联网尝试下载并嵌入朋友圈图片」后，程序才会访问动态中记录的微信媒体地址，历史地址可能已经过期。

## 🔧 技术架构

- **后端**: Python + FastAPI + SQLCipher
- **前端**: React 18 + Vite + TailwindCSS
- **数据库解密**: pymem (内存读取) + WCDB 解密
- **图片识别**: 常用服务商预设、OpenAI 兼容、Anthropic、Gemini 或自定义 JSON 接口的图片输入（用户自行配置）
- **语音转写**: 常用服务商预设、OpenAI 兼容、DashScope ASR 或自定义 multipart 接口（用户自行配置）
- **AI 分析**: 常用服务商预设、OpenAI 兼容、Anthropic、Gemini 或自定义 JSON 接口的文本分块汇总（用户自行配置）
- **数据导出**: 聊天记录与朋友圈 HTML / JSON / CSV / TXT

## ⚠️ 注意事项

1. **本地处理范围**: 浏览、解密与导出默认在本机运行；图片识别、语音转写、AI 分析和朋友圈媒体下载只在用户明确触发后联网
2. **管理员权限**: 如果使用内存提取密钥功能，可能需要以管理员身份运行
3. **杀毒软件**: 内存读取操作可能触发安全软件告警；请先确认下载来源、版本和校验和，无法确认时不要绕过告警或添加信任
4. **微信版本**: 不同版本的微信数据库结构可能略有差异
5. **密钥安全**: 提取的数据库密钥保存在当前 Windows 用户的 `%LOCALAPPDATA%\WechatAnalysisAssistant\wechat_keys.json`，不会再写入源码或安装目录，请只在受信任的 Windows 账号中使用
6. **API Key 安全**: 图片识别、语音转写和 AI 分析配置保存在 `%LOCALAPPDATA%\WechatAnalysisAssistant\settings.json`；普通设置接口只返回掩码状态，不返回原文
7. **图片缓存限制**: 只能显示微信仍保存在本机的图片；从未下载或已被微信清理的图片无法恢复
8. **朋友圈范围**: 朋友圈导出目前只支持微信 4.x，且只能导出电脑版微信本机已经缓存的动态快照
9. **自动提取组件**: `wx_key` Hook 是可选增强组件，公开源码和默认安装包不会捆绑；缺少组件时使用本机内存扫描，并始终保留手动输入方式。只有已自行确认使用与再分发授权的维护者才应显式构建包含该组件的内部版本

## ❓ 常见问题

**Q: 无法自动提取密钥？**
- 确保微信正在运行且已登录
- 尝试以管理员身份运行程序
- 可以手动输入密钥

**Q: 密钥验证失败？**
- 检查密钥格式是否正确 (64 位十六进制)
- 确认微信版本兼容性
- 尝试重新提取密钥

**Q: 前端页面打不开？**
- 检查后端是否正常启动
- 确认端口 8520 未被占用
- 使用 `.venv\Scripts\python.exe -m backend.main --port 8080` 更换端口

**Q: 消息显示不全？**
- 非文本消息 (图片/视频/语音/文件) 会显示类型标签如 `[图片]`、`[表情]`
- 点击「刷新」按钮同步微信最新消息
